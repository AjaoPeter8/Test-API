# **Personal Info & Cat Fact API** 🐱

## Overview
This is a minimalistic Node.js Express API designed to serve predefined personal developer information and integrate with an external API to fetch random cat facts. It leverages `express` for robust API routing and `axios` for efficient asynchronous HTTP requests.

## Features
- **Express.js**: Provides a powerful, unopinionated framework for building web applications and APIs.
- **Axios**: A promise-based HTTP client used for making requests to external APIs, specifically the Cat Fact API.
- **Body-Parser**: Middleware for parsing incoming request bodies, making it easy to handle JSON and URL-encoded data.
- **Personalized Data**: Serves static personal details, demonstrating basic data exposure.
- **External API Integration**: Dynamically fetches and includes data from `https://catfact.ninja/fact`.

## Getting Started
To get this API up and running on your local machine, follow these steps:

### Installation
1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    ```
2.  **Navigate into the project directory:**
    ```bash
    cd hng
    ```
3.  **Install project dependencies:**
    ```bash
    npm install
    ```
4.  **Run the application:**
    *   To run in development mode (with hot-reloading, requires `nodemon`):
        ```bash
        # If nodemon is not installed, install it globally: npm install -g nodemon
        nodemon index.js
        ```
    *   To run in production mode:
        ```bash
        node index.js
        ```
    The API will start on `http://localhost:3000`.

### Environment Variables
The application uses a default port of `3000`. You can override this by setting the `PORT` environment variable.

```bash
# Example: Running on port 8080
PORT=8080 node index.js
```

## API Documentation
### Base URL
`http://localhost:3000` (or the port specified by your `PORT` environment variable)

### Endpoints
#### GET /me
Retrieves personal developer information along with a dynamically fetched cat fact.

**Request**:
This endpoint does not require any request body or query parameters.

**Response**:
```json
{
  "status": "Success",
  "user": {
    "email": "oluwafemipeter02@gmail.com",
    "name": "Ajao Peter Oluwafemi",
    "stack": "Node.js/Express"
  },
  "timestamp": "2024-07-30T12:34:56.789Z",
  "fact": "Cats can make over 100 different sounds whereas dogs can only make about 10."
}
```
*Note: The `timestamp` and `fact` fields will vary with each request.*

**Errors**:
- `500 Internal Server Error`: Occurs if the application fails to fetch a cat fact from the external API (e.g., due to network issues, API downtime, or timeout). The `fact` field in the response will indicate "Failed to fetch".

## Usage
Once the server is running, you can access the API endpoint using any HTTP client (e.g., Postman, Insomnia, or your web browser).

Open your browser or an API client and navigate to:
`http://localhost:3000/me`

You will receive a JSON response containing the personal user data and a new cat fact with each request.
